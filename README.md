### 👨‍💻 About Me

I'm a self-taught developer who loves turning complex tasks into simple, beautiful tools.  
My philosophy is simple: **software should be lightweight, offline-first, and respect user privacy**. No telemetry, no bloat, no cloud lock-in.

I build tools that I personally use every day — from local AI assistants to seamless cloud-to-SFTP bridges and virtual machine managers. Every project starts as a solution to my own workflow problems on Linux, then I open-source it so others can benefit too.

Currently building a full suite of developer productivity tools. Future plans include cross-platform releases (Windows/macOS) and even web-based versions of some utilities.

### 🔥 Featured Projects

**ollama-forge**  
A beautiful, fully offline local AI desktop GUI built on Ollama. Features chat, RAG knowledge base, multi-agent crews, model management, and zero cloud dependency. Perfect for developers who want powerful AI without sending data anywhere.

**cloud-forge**  
Turn Google Drive, Dropbox, OneDrive, Mega or S3 into a blazing-fast SFTP server in one click. Powered by rclone + PyQt6 GUI. Ideal for developers who need secure, scriptable access to cloud storage.

**virt-forge**  
Modern QEMU virtual machine manager with clean PyQt6 interface. Create, manage, snapshot and monitor VMs with drag-and-drop disk handling. Built for Linux power users who want full control without heavy GUIs.

**easy-ssh-dev**  
Passwordless SSH manager (CLI + GUI). One command to setup keys, connect, and manage multiple servers. Made for developers who hate typing passwords every time.

**quick-creator**  
Lightning-fast project scaffolding tool. Choose template → instant folder structure + boilerplate files. Saves hours when starting new Python, Go, or Flutter projects.

**sftp-forge**  
Lightweight SFTP client and automation toolkit. Batch transfers, auto-sync rules, and SSH key management — all in a tiny desktop app.
