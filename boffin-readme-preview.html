🏗️ How I Build

  • 01Scratch your own itch first — if I don't need it, I don't build it
  • 02CLI first, GUI second — the CLI is always fully functional on its own
  • 03Single binary or AppImage — no complex install steps for end users
  • 04Safe shell scripting — set -euo pipefail, printf over echo, no bashisms in POSIX scripts
  • 05Portable by default — ARM64/proot support from day one where feasible
  • 06Acknowledge upstream — every README credits the open-source tools it depends on
